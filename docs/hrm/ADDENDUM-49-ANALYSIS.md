| D-25 | HRM uploads (coordinator's decision, `Services/HrmAttachments.cs`). **Read:** the five kinds (`KeepsUploadsPrivate`) are read only through `api/hrm/attachments`; `api/attachments` content and list refuse them (403), because that controller knows a permission but not whose row holds the file. The row decides: self (`HRM_SELF_SERVICE` + own employee), or the kind's HR code + `CanAccessAsync`; a candidate's resume asks the recruitment service's own scope. A file no row holds is its uploader's alone. Anything else is 404; no HRM code at all is 403. **Save:** every save site (leave, expense line, employee photo, employee document, resume, certificate) requires the uuid to exist in this organization, be the right kind and be uploaded by this caller, else 400 `HRM_ATTACHMENT_INVALID`. The uploader condition goes beyond the decision on purpose: without it, pasting a uuid from someone else's row would grant read access through your own row. A uuid the row already holds is not rechecked, so another user can edit that row. Pay has no save site: its files are generated. **Remove:** `DELETE api/hrm/attachments/{uuid}` erases the bytes, uploader only, 409 `ATTACHMENT_IN_USE` while a row (deleted rows included) holds it. **Limits left:** (1) orphan files: an abandoned form, a closed tab, a replaced file or a removed employee document leaves bytes in the database until the uploader removes them; there is no purge job and no one else can remove them, though only that uploader can read them. (2) HR must upload and save as the same user; a file uploaded by one user cannot be attached by another. (3) The remove check and a concurrent save are not atomic: a save landing between them would hold a removed file, which then reads 404. (4) The read routes are gated by `MODULE_HRM`, not the sub-feature: with Recruitment off, a recruiter's permission still reads a resume. |

**Limitation (G-17, task 094):** one organization = one employer = one payroll legal entity. Groups use separate organizations; no consolidation.

| D-ATT-2 | Day rules. Late = whole delay once past grace; early = whole gap once past GraceOut; overtime = all minutes beyond the shift once past the threshold. Worked on a holiday or weekly off is all overtime (past the threshold), status stays Holiday/WeeklyOff. A half-day leave excuses lateness and the short day.
