# Addendum 49 — schema requests

**CORE alone** changes hrm entities, maps, `HrmDbContext`, migrations, seeds, permission codes and the catalog. If you need a change, add a row here and message CORE. Say which task needs it and propose the exact column (name, type, nullability). CORE batches them into a new guarded migration and answers in the Decision column. Never edit `Domain/`, `Data/` or `Migrations/` yourself: a second writer breaks the snapshot, and EF 9 refuses `Migrate()` on pending model changes, which stops the API at startup.

Non-HRM schema (Integration, Accounting, Finance, Tenancy): same process.
